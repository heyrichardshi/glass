# 🧧 Saffron - powerful cash flow analysis and budgeting

## Setting Up

1. Download [DynamoDB local](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/DynamoDBLocal.DownloadingAndRunning.html) and extract the files somewhere permanent.
1. Run `java -Djava.library.path=./DynamoDBLocal_lib -jar DynamoDBLocal.jar` to start DynamoDB.
